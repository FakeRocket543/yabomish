# 關於 Yabomish

嘸蝦米輸入法 for iOS / macOS。

## 版本

請見應用程式主視窗或關於頁面版本資訊。

## 快捷鍵

### 鍵盤命令

以 `,,` 開頭輸入命令：

- `,,ZH` 注音查碼
- `,,TO` 進入同音字查詢
- `,,RL` 重載字表及擴充表
- `,,H` 完整命令說明

### 按鍵

- `Shift` 中／英文切換
- `空白鍵` 送出候選字
- `Shift + Space` 全形空白

## 資料路徑

- 字表：`~/Library/Application Support/Yabomish/liu.cin`
- 字頻學習資料：`~/Library/Application Support/Yabomish/freq.db`
- 擴充表：`~/Library/Application Support/Yabomish/tables/*.txt`
- 除錯記錄：`~/Library/Application Support/Yabomish/debug.log`
