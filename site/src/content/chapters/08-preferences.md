Yabomish 的所有設定都集中在獨立的設定程式 **YabomishPrefs.app** 中，採系統設定式的側邊欄格局，共 **12 個頁面**調整輸入行為、中英切換、英數聯想、聯想詞庫、快捷碼、候選窗與介面外觀；頂部搜尋欄可直接打關鍵字跳到對應設定。

---

## 開啟方式

- 直接開啟 `/Applications/YabomishPrefs.app`
- 或在狀態列的 Yabomish 圖示上**按右鍵** → 選擇「**偏好設定**」

### 首次使用引導

第一次開啟設定程式時，會出現四頁引導流程（code `WelcomeView` tag0..3 為準）：

1. **匯入字表** — 選擇你的 `liu.cin` 檔案，在裝置上編譯為二進位格式（已匯入會顯示狀態）
2. **登出再登入** — 僅首次安裝需要，讓系統重新載入輸入法清單
3. **加入輸入方式** — 引導你到系統設定 → 鍵盤 → 輸入方式，加入 Yabomish
4. **常用快捷鍵** — 速覽最常用的操作按鍵

完成引導後即可正常使用。以下逐一說明各頁。


## 8.1 輸入

此分頁控制輸入法的核心行為。

![輸入分頁](/yabomish/images/prefs-input.webp)

### 匯入字表

分頁頂部有「**匯入字表⋯**」按鈕，支援 `.cin` 和 `.txt` 格式。匯入後會在裝置上編譯為 `.bin` 二進位格式，字表內容不會上傳或外流。

### 設定項目

| 設定 | 說明 |
|------|------|
| **選字窗模式** | **游標跟隨**：毛玻璃列表，跟隨輸入游標移動（可在外觀分頁切換為橫向排列）。**固定位置**：水平列，可拖曳定位，右鍵調整對齊方式與透明度。 |
| **聯想輸入** | 開啟後，每次送字會自動建議下一個字或詞。關閉則只顯示當前輸入碼的候選字。 |
| **聯想預先反白** | 純聯想顯示（組字已空）時是否預先反白第 0 個候選。預設**關閉**——Enter、空白鍵不會代選任何聯想詞（選詞請用數字鍵）；偏好舊觀感者可開啟。組字候選一律反白第一個，不受影響。 |
| **Shift＋數字鍵** | 候選字或聯想顯示中，按住 Shift 再按數字列的輸出：**符號 !@#$%**（預設，與全系統慣例一致）或**數字 12345**（聯想中快速插入數字）。閒置狀態恆為符號；組字中 Shift+8 萬用碼不受影響。 |
| **自動送字** | 唯一候選且編碼無法再延伸（≥ 2 碼）時，自動送出，不需按空白鍵。 |
| **拆碼提示** | 送字後在選字窗短暫顯示該字的嘸蝦米碼，幫助記憶拆碼方式。注音/同音字查碼模式下顯示 3 秒，一般模式 1.5 秒。 |
| **鄰鍵容錯** | 啟用鄰鍵容錯——打錯一碼時，會自動搜尋鍵盤上相鄰按鍵的組合，仍能找到候選字。 |
| **標點配對** | 輸入左括號類標點（如「）時，自動補上對應的右括號（」）。macOS 預設為關閉。 |
| **同音多讀** | 開啟後，同音字查詢會包含罕見讀音的結果，涵蓋範圍更廣。 |
| **同音字自動退出** | 開啟後，同音字查詢選字後即自動退出同音字模式，無需再輸入 `,,TO`；關閉時須手動以 `,,TO` 離開。預設為關閉。 |

### 選字窗 Demo 預覽

設定項目下方會根據選擇的選字窗模式（游標跟隨 / 固定位置）顯示即時預覽。

### 固定同碼字排序

輸入分頁底部的「固定同碼字排序」區塊，可在設定程式中直接管理固定排序：

1. 輸入碼（如 `a`），按 Enter 或點「查詢」列出候選字
2. 點擊候選字加入固定順序，用上下箭頭調整排列
3. 按「儲存」寫入 freq.db，輸入法即時生效

也可在輸入時用 `,,PIN` 命令操作（詳見[第四章](/yabomish/chapters/04-modes-and-commands)）。

### 查字歷史

反查模式（注音／同音字／拼音）選字送出時自動記錄——這份清單就是「不會拆碼的字」：

- **檢視**：列出全部反查選字記錄（字、碼、查詢方式）
- **匯出 CSV**：UTF-8 BOM 格式，可匯入其他工具複習
- **清除**：一鍵清空（`,,RS` 重置字頻不影響查字歷史）
- 輸入法內可用 `,,LH` 檢視最近 20 筆、`,,RH` 清除

## 8.2 切換

此頁控制中／英模式怎麼切換，以及安全欄位的放行行為。

### 中英切換鍵

四張選項卡擇一：

| 選項 | 說明 |
|------|------|
| **Shift 快按**（預設） | 0.3 秒內輕點 Shift 切換中／英 |
| **⇪ Caps Lock** | ⇪ 變專用切換鍵——系統大寫鎖定會被自動壓回（LED 不亮、大寫改由 Shift＋字母）；macOS 會丟棄過快的輕點（<100ms），需**稍長按** |
| **兩者皆可** | Shift 快按與 ⇪ 都能切換；⇪ 同樣被壓回非大寫 |
| **全都不用** | 鍵盤不切換，英文改從輸入法選單點選；Caps Lock 恢復正常大寫語意 |

### 密碼／安全欄位

| 設定 | 說明 |
|------|------|
| **密碼欄位照打**（預設關） | macOS 安全輸入啟用時（密碼欄、Keychain 對話框等），輸入法預設暫停、按鍵原樣送達——避免組字緩衝、字頻學習、debug 記錄接觸密碼。某些 app 會卡住安全輸入不放導致整個 app 無法輸入，開啟後可強行使用。**無論是否開啟，安全期間 debug 記錄與字頻學習一律靜音** |

## 8.3 英數

此頁管理英文模式的補全與個人詞庫。

| 設定 | 說明 |
|------|------|
| **英文聯想輸入**（預設開） | 英文模式打字時，候選窗即時顯示單字補全（約 1 萬常用詞＋自訂詞）；數字鍵或點選送字。沒有匹配且打滿 3 個字母時，候選列出現「＋前綴」可把新詞加入自訂詞。密碼欄位不啟用 |
| **自訂詞** | 英文模式下選「＋前綴」候選時自動收錄的詞，此處可刪除或清空 |

## 8.4 聯想

此分頁管理聯想輸入的層序（三層文字來源＋Emoji 卡）與詞庫來源。

![聯想與詞庫](/yabomish/images/prefs-suggest-top.webp)

### 語境切換器

分頁頂部的語境列可一鍵切換輸入法的完整語境——輸入模式、聯想策略、詞庫組合、地區用詞同時切換。

- 點擊按鈕切換語境，當前語境高亮顯示
- 右鍵可「編輯」（彈出 sheet 修改所有欄位）或「複製」為新 profile
- 點「+ 新增」從目前設定建立新語境（需輸入名稱、2 字母命令碼、icon）
- 「重置」按鈕回到預設語境
- 支援匯入匯出（JSON 格式）
- 最多 10 組語境

預設 4 組語境：

| 命令碼 | 名稱 | 說明 |
|--------|------|------|
| `,,XDF` | ⌨️ 預設 | 無專業詞庫，乾淨狀態 |
| `,,XTW` | 🇹🇼 台式 | 萌典、成語、台灣俗諺、地名、晶晶體 |
| `,,XCH` | 🇨🇳 中式 | 簡中模式、中國流行語 |
| `,,XTC` | 💻 科技 | 資訊、電機、數學、晶晶體 |

也可在輸入時使用 `,,X` + 命令碼快速切換。`,,XS` 儲存當前設定到語境，`,,XI` 顯示當前語境名稱，`,,XRS` 重置為預設。

### 用詞習慣

選擇「臺灣用詞」或「中式用詞」。影響候選字排序——選定一側的常用詞會優先顯示，對側用詞降權。基於國家教育研究院（NAER）兩岸用詞對照表。

### 聯想層順序

聯想輸入由三層文字來源＋第四張 **Emoji 聯想卡**組成，每張卡以卡片呈現，可**拖拉調整優先順序**（字級聯想與 Emoji 卡點擊即啟用／停用）：

| 層級 | 說明 |
|------|------|
| **詞級語料** | 從大型語料庫中擷取的詞組建議 |
| **詞庫** | 各類主題詞典的詞組 |
| **字級聯想** | 基於 bigram / trigram 統計預測的下一字 |

拖拉卡片即可改變層序，例如把詞庫拉到最上面，就會優先顯示詞庫中的詞組；Emoji 卡排最前時固定顯示（預設）、排其他位置時聯想列有空位才顯示、點擊關閉。

### 詞級語料來源

可切換三種語料來源：

- **萌典**（教育部辭典）— 標準、正式的詞組
- **維基百科** — 涵蓋面廣，包含專有名詞
- **新聞語料** — 貼近時事用語

### 字級聯想

獨立開關，控制是否啟用 bigram / trigram 的單字預測。

## 8.5 一般詞庫

共 **12 張卡片**，每張代表一個詞庫類別：

> NER 詞組、萌典詞組、成語、晶晶體（台式中英夾雜）、中國流行語、歇後語、台灣俗諺、客語辭典、台灣地名、學科術語、韓語漢字詞、日本熟語

## 8.7 快捷碼

此分頁管理自訂快捷碼，詳細概念請參閱[第七章](/yabomish/chapters/07-shortcuts-and-extensions)。

![快捷碼](/yabomish/images/prefs-shortcuts.webp)

### 詞庫查詢

頁面頂部的搜尋欄可查詢任意中文詞是否已收錄於詞庫中：

1. 輸入 2 字以上的中文詞，按 Enter 或點「查詢」
2. 結果以表格顯示：左欄為詞庫名稱，右欄為實際匹配的詞條
3. 點「匯出 CSV⋯」可將查詢結果存檔

### 新增快捷碼

1. 在「編碼」欄輸入 2～4 個字母
2. 在「內容」欄輸入要送出的文字（支援 `\n` 換行）
3. 按下「加入」

系統會**自動檢查**：
- 編碼長度是否在 2～4 碼範圍內（不足或超過會提示）
- 該碼是否已被嘸蝦米字表佔用（衝突時提示更換）
- 該碼是否已有快捷碼（重複時提示將覆蓋）

### 列表管理

- 上方搜尋欄可快速篩選
- 點擊 ✎ 按鈕或雙擊列表項目可編輯
- 選取後按刪除鍵或點擊刪除按鈕移除

### 匯入匯出

支援 tab-separated 的 `.txt` 檔案格式，`#` 開頭為註解行（可用來分類），方便備份、還原或與他人分享。匯入時會自動驗證每筆編碼的長度（2–4 碼）並檢查字表衝突，不合法的碼會被略過，完成後顯示匯入結果摘要（新增、覆蓋、略過筆數）。

### 空碼統計

分頁底部顯示目前 **4 碼空碼的剩餘數量**，讓你掌握還有多少碼可供綁定。

## 8.8 候選窗

此頁調整選字窗的位置、字體與顯示行為。

### 選字窗位置

| 選項 | 說明 |
|------|------|
| **游標跟隨** | 毛玻璃列表跟隨輸入游標 |
| **固定位置** | 水平列固定於螢幕底部，可拖曳定位 |

下方即時預覽目前選中的模式。

### 字型大小

| 設定 | 說明 |
|------|------|
| **游標模式** | 游標跟隨選字窗的文字大小（10–30 pt） |
| **固定模式** | 固定位置選字窗的文字大小（10–30 pt） |

### 候選字體

字體、字色與描邊同時套用於候選窗與模式提示；反白列保留系統選取色。

| 設定 | 說明 |
|------|------|
| **字型** | 系統／圓體／明體／黑體／楷體 |
| **字色** | 自訂候選文字顏色 |
| **描邊** | 開關＋描邊色；開啟後可加 0.5–4 px 粗細調整 |

### 固定窗背景

| 設定 | 說明 |
|------|------|
| **透明度** | 固定位置選字窗的背景透明度（30–100%） |
| **對齊** | 候選在固定列內的左／中／右對齊 |
| **垂直偏移** | 固定列的上下位移（0–64 pt） |

### 顯示

| 設定 | 說明 |
|------|------|
| **橫向候選** | 游標模式下候選橫排（預設直排）；開啟後方向鍵 ←→ 移動候選、↑↓ 翻頁 |
| **高對比** | 候選字加粗＋陰影，方便視覺辨識 |

## 8.10 介面

| 設定 | 說明 |
|------|------|
| **介面外觀** | 三態：自動（跟隨系統深淺色，預設）／淺色／深色——套用於候選字窗、固定模式列與切換提示，設定視窗同步切換方便預覽 |

## 8.11 AI

`,,AI` 與 preset（`,,IG`／`,,PR`）共用的後端設定，切換即時生效：

| 設定 | 說明 |
|------|------|
| **模式** | `CLI 指令` / `HTTP Provider` 二擇一 |
| **CLI 指令樣板**（`aiCommand`） | argv 以空白切：第一欄可執行檔、`{prompt}` 整欄替換、`{clip}` 代剪貼簿；沒寫 `{prompt}` 自動加在最後一欄。預設 `/usr/bin/fm respond {prompt}`（macOS 27+ Apple Intelligence，本機、免 key）；可換 ollama／llama.cpp／claude 等任何「接 prompt、吐 stdout」的 CLI |
| **HTTP Provider** | OpenAI Chat Completions 相容端點。Provider 下拉從 models.dev catalog 帶 base URL＋模型清單（含 OpenAI/Anthropic/Google/OpenRouter/ollama-cloud 等），自訂端點直接填 base URL（如 `fm serve` → `http://127.0.0.1:11434/v1`）。`aiBaseURL`/`aiModel`/`aiAPIKey` 三欄，API key 存本機 plist、GUI 遮蔽顯示；逾時 60 秒 |
| **Preset 編輯器** | commands.json `type:"preset"` 條目的 GUI：key=指令碼、name=顯示名、prompt 樣板（`{clip}`/`{input}` 佔位符）。儲存即時生效，不需 `,,RL` |

用法詳見[第七章 7.4](/yabomish/chapters/07-shortcuts-and-extensions)。

## 設定檔位置

所有偏好設定儲存在 macOS 標準的 UserDefaults 中，由 Yabomish 輸入法與設定程式共用。修改設定後立即生效，不需要重新啟動輸入法。
